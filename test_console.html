Console ทดสอบระบบแจ้งเตือน LINE

ยิง request เข้า backend จริง เพื่อทดสอบก่อนต่อกับระบบของเพื่อนคุณ
ยังไม่เช็คการเชื่อมต่อ

กรณีที่ 1 — user แจ้งข้อความ POST /messages

จำลองว่า user พิมพ์ฝากข้อความถึงช่างเข้ามา จะยิงแจ้งเตือน LINE รอบแรกทันที

Assign งาน PATCH /tickets/:id/assign

มอบหมายงาน ticket ที่มีอยู่แล้วให้ช่าง จะยิงแจ้งเตือน LINE (แท็กชื่อได้ถ้าช่างลงทะเบียนแล้ว)

กรณีที่ 2 — จนท. สร้างเอง POST /tickets/staff-create

เจ้าหน้าที่สร้างงานและ assign พร้อมกันในขั้นตอนเดียว ยิงแจ้งเตือนครั้งเดียว

ช่างที่ลงทะเบียนแล้ว GET /technicians

รายชื่อช่างที่พิมพ์ "ลงทะเบียนช่าง ..." ในกลุ่ม LINE แล้ว และระบบจับ userId ไว้ให้
